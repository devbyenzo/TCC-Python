# ⚡ Multi Tools

Aplicativo desktop desenvolvido em **Python** utilizando CustomTkinter com foco em reunir múltiplas ferramentas úteis em uma única interface moderna, organizada e intuitiva.

> 🚧 Projeto atualmente em desenvolvimento.

---

# 📌 Sobre o Projeto

O **Multi Tools** foi criado como projeto de **TCC (Trabalho de Conclusão de Curso)** com o objetivo de desenvolver uma aplicação desktop moderna utilizando Python e interfaces gráficas avançadas.

A proposta do sistema é centralizar diversas ferramentas e utilidades em um único aplicativo, oferecendo praticidade, organização e uma experiência visual premium.

---

# 🚀 Funcionalidades Atuais

Atualmente o projeto possui:

- ✅ Consulta de CPF
- ✅ Consulta de CNPJ
- ✅ Busca de CEP
- ✅ Calculadora de IMC
- ✅ Calculadora de Média
- ✅ Calculadora Fatorial
- ✅ Calculadora de Áreas
- ✅ Sistema de navegação lateral
- ✅ Interface moderna em Dark Mode
- ✅ Header dinâmico
- ✅ Estrutura modular

---

# 🛠️ Tecnologias Utilizadas

- Python
- CustomTkinter
- Requests
- Pillow (PIL)
